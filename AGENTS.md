# Global Codex working agreements

- Prefer small, incremental changes with clear checkpoints.
- When editing code, preserve existing style and patterns.
- If uncertain, propose 2-3 options with tradeoffs and pick a default.
- Never invent metrics or business facts; request/derive them from data sources or fixtures.
- When asked for a PR plan, write an actual PR-by-PR execution plan in the requested file, then in the response say what the immediate next step is and ask whether to proceed.
- After each completed change, create a normal git commit and push it to `origin` on the current branch unless the user explicitly says not to.
- Do not leave completed work uncommitted or unpushed at the end of a turn when a push is possible.
